## 👋 Sobre mí

Consultoría SAP Sénior / Arquitectura de software y de datos en Brasil, con casos en América Latina, **20 años en TI** y SAP desde ambos lados: implementé **SAP Business One** como gerente de TI de una industria y hoy diseño add-ons, integraciones y estructuras de datos en una software house **SAP Gold Partner** enfocada en el agronegocio.

- 🧭 Traduzco reglas de negocio y problemas de usuario en **especificación y modelo de datos**, y guío a la IA para convertirlo en código revisado.
- 🗄️ Bases de datos que administro y modelo: **SAP HANA, SQL Server, Oracle, PostgreSQL y Firebird**.
- 🤖 Conduzco **desarrollo guiado por especificación (SDD) con Claude** (Claude Code, skills y MCP), desde el ticket del cliente hasta el pull request aprobado.
- 🌾 Dominio sólido en **agro** (algodón, semillas, granos, fertilizantes), **finanzas, crédito, importaciones e integración bancaria**.
- 🔭 Hoy: arquitectura **clean core** para SAP B1, integraciones vía **Service Layer / SAP BTP** e IA aplicada al ERP.
